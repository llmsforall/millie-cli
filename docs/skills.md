# Skills

A skill is a folder containing a `SKILL.md` file (and optionally scripts and
reference material) that teaches Millie how to do a specific kind of task.
Millie sees each skill's name and description and reads the rest only when it
decides the skill applies.

Put your own skills in `~/.millie/skills/<name>/SKILL.md`. Millie also ships a
few built-in ones, installed under `~/.millie/skills/.system/`, including
`skill-creator`, which walks you through writing a new skill. `/skills` inside
a session lists what is available.
