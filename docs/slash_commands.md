# Slash commands

Type `/` in a session to open the command list. The ones you will reach for
most:

| Command                                     | What it does                                                                                              |
| ------------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| `/model`                                    | for local models, explains startup selection; use `millie --model select` after closing existing sessions |
| `/permissions`                              | choose what Millie is allowed to do                                                                       |
| `/compact`                                  | summarise the conversation to free up context                                                             |
| `/new`, `/clear`                            | start a new chat                                                                                          |
| `/resume`, `/fork`                          | resume a saved chat, or fork the current one                                                              |
| `/review`                                   | review the current changes and find issues                                                                |
| `/diff`                                     | show the git diff, including untracked files                                                              |
| `/status`                                   | show the current configuration and token usage                                                            |
| `/init`                                     | create an AGENTS.md with instructions for Millie                                                          |
| `/skills`, `/mcp`, `/hooks`                 | list skills, MCP tools and lifecycle hooks                                                                |
| `/plan`                                     | switch to plan mode                                                                                       |
| `/goal`                                     | set or view the goal for a long-running task                                                              |
| `/side`                                     | start a side conversation without polluting the main thread                                               |
| `/copy`                                     | copy the last response as Markdown                                                                        |
| `/personality`, `/theme`, `/keymap`, `/vim` | appearance and input preferences                                                                          |
| `/quit`                                     | exit Millie                                                                                               |
